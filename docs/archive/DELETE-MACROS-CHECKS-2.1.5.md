# Удаление макросов — 2.1.5

Реализация: корзина справа от каждого сохранённого макроса. Удаление по ID файла,
а не по названию. В подтверждении по умолчанию фокус на «Отмена»;
под вопросом отдельным мелким текстом указан срок хранения 30 дней.
Файл перемещается без перезаписи в `%LOCALAPPDATA%\MacroClicker\Macros\Deleted`.
В имени архива хранится UTC-время удаления. Через 30 дней файл подлежит очистке.
Проверка: запуск, открытие корзины, раз в час при отсутствии выполнения/записи и диалогов.
Корзина показывает оставшиеся дни, позволяет восстановить макрос в библиотеку
без замены текущего черновика или очистить всё с предупреждением о необратимости.
Неизвестная дата не угадывается по времени изменения исходного JSON: такие файлы
могут быть восстановлены/очищены вручную. Автоматическая очистка их не затрагивает.

Проверено на Mac:

- `dotnet run --no-restore --project tests/EngineChecks.csproj`: 41/41 проверок движка/хранилища и 29/29 проверок записи.
- `node tests/WebLibraryDelete.cjs`: запрос удаления по ID, отсутствие удаления до ответа,
  блокировка при выполнении, одинаковые названия, сохранение JSON-черновика, поиск,
  отмена и сброс активного макроса в предпросмотре.
- `node tests/WebDirtyState.cjs`: 8/8.
- `node tests/WebKeyCapture.cjs`: 16/16.
- `node tests/WebStartupChecks.cjs`: 7/7.
- `node tests/WebStepLabels.cjs`: 8/8.
- `node tests/WebTrash.cjs`: пустая корзина, оставшийся срок, неизвестная дата,
  восстановление по ID и сохранение текущего редактора.
- Браузерный предпросмотр: сохранение тестового макроса, кнопка корзины,
  подтверждение удаления, исчезновение из списка и пустой редактор.

Нужно проверить на Windows (на Mac эти проверки не выполнялись):

1. Удаление неактивного макроса при несохранённом, в том числе невалидном JSON другого.
2. «Отмена» и Escape сохраняют файл, активный документ и черновик.
3. Удаление активного макроса с изменениями: предупреждение, новый пустой сценарий.
4. Перезапуск приложения: удалённый макрос не появляется вновь.
5. Ошибка доступа к Deleted: видимая ошибка и сохранение исходного файла/редактора.
6. Восстановление из корзины; остальные макросы и текущий JSON-черновик не затронуты.
7. Удаление недоступно при записи/выполнении; горячая клавиша не запускает макрос при подтверждении.
8. Очистить корзину: «Нет» сохраняет файлы; «Да» удаляет только макросы корзины.
9. Автоочистка на запуске/по таймеру: старые удаляются, свежие остаются; при ошибке доступа есть запись в журнале.
