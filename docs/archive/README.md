# Исторические материалы

Здесь сохранены отчёты прошлых выпусков и диагностика. Команды и пути внутри них отражают структуру на момент проверки; использовать их как текущую инструкцию не следует.

- `TEST-RESULTS-2.1.4.md` — накопленный отчёт ранних версий, включая старые результаты локальных Windows-сборок.
- `DELETE-MACROS-CHECKS-2.1.5.md` — проверки корзины и удаления.
- `NUGET-DIAGNOSTICS.md` — разбор прежней ошибки NU1900; доступен также из встроенной справки.
- `legacy-package-SHA256.txt` — контрольные суммы старого локального комплекта. Они не относятся к текущим исходникам или будущему релизу. Для скачанного EXE используйте SHA256.txt именно его релиза.
