# Дополнительные действия: итоговый план реализации

База: main `1515aad7c015482043176fc4a6bc5cf42b5ccb2f` (2.1.5), проверена 2026-09-09.
Реализация разрешена пользователем в текущей задаче. Публикация и выпуск требуют отдельной команды.

Первоначальный план считал циклы всего сценария. После обсуждения контракт изменён: дополнительные ноды привязаны к конкретной основной ноде и исполняются непосредственно после неё. Пользователь также добавил паузу перед следующей нодой и уточнил компактный вид карточки с небольшим выступом вниз и вправо.

Актуальный контракт и порядок проверки: [PERIODIC-ACTIONS.md](../user/PERIODIC-ACTIONS.md).

- [x] Модель PeriodicAction в MacroNode, пауза TransitionDelayMs, Version 3 и чтение v1/v2.
- [x] Копирование и валидация, общий лимит нод и условий, запрет вложенных условий.
- [x] Независимый планировщик на основную ноду, монотонное время, отсутствие догоняющих запусков.
- [x] Последовательное исполнение, отпускание удержаний, Stop, контроль фокуса и возврат окна.
- [x] Передача привязок окон между WebView2 и моделью, очистка привязок в файлах.
- [x] Компактные карточки и редактор; порядок условий; паузы на переходах; JSON без ложного dirty-state.
- [x] Проверки модели, расписания, исполнения, редактора и совместимости; браузерная проверка нескольких нод в обеих темах.
- [x] Справка, примеры, версия 2.1.6 и описание будущего выпуска.
- [ ] Windows-сборка через GitHub Actions — не запускалась в этой задаче.
- [ ] Ручная проверка Windows-ввода — требуется перед выпуском.
- [ ] Публикация — только по отдельной команде пользователя.

Исходники на рабочем столе не должны содержать EXE; локальная сборка Windows-пакета и копирование на флешку в объём не входят.
