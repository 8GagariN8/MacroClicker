# MacroClicker 2.1.6

Ввод сочетаний: «Действие → Клавиши» → названия через `+` (например, `Ctrl+Shift+S`)
или «Захватить сочетание» → нажать клавиши вместе → отпустить → сохранить действие.
Список подсказок выбирает одну клавишу; сочетание можно дописать в поле.
При отмене/потере фокуса захват не меняет поле. Системные сочетания, которые перехватывает Windows,
вводите текстом. Для смены языка — `Alt+Shift`/`Win+Space` согласно настройкам Windows.

Тема страницы синхронизируется с PreferredColorScheme профиля WebView2 для браузерных списков,
при загрузке, сохранении, предпросмотре и отмене настройки темы.

В редакторе номер шага отделён от действия. Клавиши показаны отдельными плашками:
«Нажать клавишу [4]», «Нажать сочетание [Ctrl] + [Shift] + [S]».
Удержание и отпускание подписаны явно; NumPad отличается от верхнего цифрового ряда.
Подсказка при наведении на клавишу показывает исходное обозначение из макроса.
Это только отображение: Input, Action и интервалы не изменяются.

Переключение «Сценарий → JSON → Сценарий» не помечает макрос изменённым.
Форматирование, пробелы и порядок полей JSON также не меняют статус сохранения.
Существующие несохранённые правки сохраняют свою отметку; некорректный JSON не теряется при попытке переключения.

При запуске отображается анимированный лоадер и этап подготовки. После запуска кнопка «Журнал»
в боковом меню открывает текущие записи: обновление, копирование и папку журналов.
Отдельные файлы `%LOCALAPPDATA%\MacroClicker\Logs\session-*.log` сохраняют ошибки и жизненный цикл
выполнения/записи после закрытия приложения. Шаги, вводимый текст и записанные клавиши намеренно не пишутся;
технические исключения могут содержать пути к файлам. Если WebView2 перестал работать,
диагностика и кнопка журнала доступны в нативной панели, без веб-интерфейса.

Windows-приложение для создания, записи и воспроизведения макросов в выбранных окнах. Автономная сборка Windows x64 не требует установки .NET.

Интерфейс работает через Microsoft WebView2 Runtime. Если он установлен, достаточно MacroClicker.exe. Если нет — однократно запустите официальный офлайн-установщик из папки Runtime, затем MacroClicker.exe. Интернет для интерфейса и макросов не нужен. Справка встроена в EXE; кнопка «Справка» находится слева внизу. Исходники для запуска не нужны. Макросы и настройки записываются в %LOCALAPPDATA%\MacroClicker; при переносе экспортируйте нужные макросы в JSON.

## Интерфейс и сценарии

Слева находятся поиск и библиотека макросов. Нажмите сохранённый макрос, чтобы открыть его. В центре — переключатель «Сценарий / JSON». Один узел содержит список действий в выбранном или текущем активном окне. Узлы выполняются сверху вниз; «Редактировать» открывает содержимое. Меню «…» карточки позволяет переименовать, переместить, дублировать или удалить узел.

«Переименовать» в меню карточки открывает редактор с выделенным именем, включая импортированный узел. Сохранить имя и действия можно без доступного окна. Переименование не меняет заголовок целевого окна.

Редакторы узлов, действий и настроек используют единое оформление: мягкие карточки, типографику Segoe UI, спокойные нейтральные цвета, светлую и тёмную темы. Нижняя панель содержит повторы, краткую сводку, сочетания клавиш и квадратную кнопку запуска. Выбор типа действия — набор понятных плиток, поля меняются в зависимости от типа.

Чтобы выполнить действия в окне A, затем B, затем снова A, создайте три узла A → B → A. Узел без действий просто переключает окно. Количество повторов относится ко всей цепочке. К основной ноде можно добавить дополнительные ноды по условию повторений или времени её работы.

Квадратная кнопка запускает и останавливает выполнение. Горячее сочетание по умолчанию — Ctrl+Alt+F8. В «Настройки» можно включить отдельную комбинацию остановки: появятся два поля. Не назначайте сочетание запуска, которое сам макрос отправляет.

«Настройки → Тёмная тема» меняет палитру и сохраняет выбор. Интерфейс использует Segoe UI, нейтральные поверхности, ограниченные цветовые акценты и интервалы 8/16/24. При высокой контрастности Windows используются системные цвета. Включён PerMonitorV2 для координат и масштабирования на разных мониторах.

Дизайн ориентирован на рекомендации Microsoft:

- [Content layout and spacing](https://learn.microsoft.com/en-us/windows/apps/design/basics/content-basics).
- [Color in Windows](https://learn.microsoft.com/en-us/windows/apps/design/signature-experiences/color).

Это локальная HTML/CSS/JS-оболочка в WebView2, размещённая в Windows-хосте WinForms, не сайт и не WinUI. src/MacroClicker/Web/index.html встроен в сборку. Внешняя навигация, новые окна, загрузки и разрешения браузера заблокированы. Данные макросов выводятся как текст; интерфейс не обращается к CDN. Нативными остаются заголовок окна, файловые диалоги и подтверждения. Движок ввода использует Windows API как и раньше.

## Дополнительные ноды и паузы перехода

«Добавить условие» на основной ноде создаёт компактную цветную карточку под ней.
Выберите запуск раз в N завершённых повторений этой ноды или по времени её работы.
Например, 1–5 в основной ноде и Enter каждые 6 повторений: Enter выполняется после
шестого, двенадцатого и последующих кратных шести проходов, до следующей основной ноды.
Дополнительные действия работают в том же окне либо в выбранном другом с возвратом обратно.
Несколько условий исполняются в порядке карточек, после отпускания удержаний.

Время учитывает только работу привязанной основной ноды, включая её внутренние паузы.
Стартовый отсчёт, остальные ноды, дополнительные действия и паузы перехода не учитываются.
Проверка выполняется на границе ноды: пропущенные интервалы не догоняются пачкой.
Новый старт сбрасывает счётчики. Потеря фокуса и Stop останавливают весь сценарий.

В редакторе каждой ноды поле «Пауза перед следующей нодой» задаёт ожидание 0–600000 мс.
Сначала идут основные действия, затем подходящие дополнительные ноды, затем пауза
основной ноды перед переходом дальше. Дополнительная нода тоже может иметь свою паузу.
Пауза последней основной ноды применяется перед повторением, но не после финального завершения.

Условия сохраняются в JSON v3, копиях и корзине. Старые файлы v1/v2 открываются с миграцией
в памяти. Версия 2.1.5 не откроет новый v3. Запись добавляет основные ноды и сохраняет условия.

## Необязательный выбор окна

В новом узле по умолчанию выбран вариант «Текущее активное окно — без выбора приложения». При наличии хотя бы одного такого узла перед стартом всей цепочки идёт отменяемый отсчёт 5 секунд. За это время перейдите в нужное приложение. Кнопка «Стоп» или назначенная горячая клавиша отменяет отсчёт.

В начале каждого такого узла берётся текущее активное окно, переключения нет. Ввод в сам MacroClicker не допускается. До конца узла сохраняется контроль фокуса: переключение на другое приложение останавливает выполнение, а не перенаправляет оставшиеся действия.

Если окно выбрано явно, оно активируется автоматически. Если оно исчезло, выполнение блокируется: переход в режим активного окна не выполняется автоматически. Это сохраняет поведение старых JSON. Чтобы сделать импортированный узел независимым от назначения, явно выберите «Текущее активное окно».

Координаты «относительно окна» в опциональном режиме относятся к окну, активному в начале узла. До запуска в статусбаре доступны экранные координаты. Для записи действий по-прежнему нужно явно назначить окна; глобальная запись всех программ не включается.

## Действия

- **Клавиша / комбинация:** буквы, цифры, F1–F24, навигация, numpad, модификаторы, OEM-клавиши, мультимедийные клавиши, поддерживаемые Windows. Можно выбрать имя или ввести комбинацию: Ctrl+C, Ctrl+Shift+S, Alt+Shift, Win+Space. Код неизвестной клавиши можно указать как VK_XX (hex). Символ «+» как клавиша: Oemplus или Add.
- **Мышь:** левая, правая, средняя, X1/X2. Режимы «нажать и отпустить», «нажать» и «отпустить».
- **Двойной клик мышью:** кнопка «+ Двойной клик» в редакторе узла либо соответствующий тип в «+ Действие». Выберите кнопку мыши и при необходимости координаты. Два нажатия и отпускания выполняются одним шагом. Удержание каждого клика и промежуток рассчитываются автоматически: четверть системного порога двойного клика, от 1 до 40 мс. «До» и «После» относятся ко всей паре; системная разделительная пауза внутри пары не добавляется. Реальное распознавание зависит от приложения и точности планировщика Windows.
- **Пауза:** отдельное ожидание. «Удержание / пауза» задаёт его длительность.
- **Текст:** до миллиона символов одним шагом, включая кириллицу, переносы и emoji. Интервал символов настраивается. Буфер обмена не меняется.
- **Перемещение:** отдельная координата курсора.
- **Колесо:** вертикальная или горизонтальная прокрутка; 120 единиц обычно соответствует делению.

Для координатного клика: задержка до → перемещение → пауза после перемещения → нажатие → удержание → отпускание → пауза после. Начальная пауза после перемещения — 100 мс, её можно настроить. Координаты считаются относительно клиентской области окна или всего виртуального экрана. Отрицательные экранные координаты допустимы для дополнительных мониторов.

Режимы «нажать» и «отпустить» позволяют удерживать кнопку через несколько шагов, например для перетаскивания. Между узлами и при завершении/отмене оставшиеся нажатые кнопки отпускаются.

Fn часто обрабатывается прошивкой клавиатуры и не является доступной Windows клавишей. Ctrl+Alt+Delete нельзя синтезировать обычным SendInput. Смена языка через Alt+Shift или Win+Space зависит от включённых раскладок и настроек Windows. Готовый Unicode-текст не зависит от выбранной раскладки, но отдельные игры с Raw Input могут его не принимать.

## Системные паузы мыши

Открываются через **Настройки → Системные паузы мыши**. Настройка сохраняется в конкретном макросе, а не меняет Windows.

Проверено по исходной реализации: старая версия использовала max(600, GetDoubleClickTime() + 100). В версии 2.0 используется **текущий GetDoubleClickTime() + 1 мс**, без дополнительного минимума 600 мс.

GetDoubleClickTime возвращает максимальный интервал распознавания двойного клика, а не обязательную задержку между обычными кликами. При включённой настройке MacroClicker ждёт, пока после предыдущего отпускания пройдёт больше этого порога. Ручные интервалы уже входят в расчёт. Значение заново читается при выполнении; таймер Windows может проснуться позже, поэтому это минимальный, а не точный интервал.

Отдельное действие «Двойной клик мышью» работает с включённой настройкой: разделительная пауза применяется между действиями, а не внутри пары. Если собираете двойной клик вручную из двух обычных действий, либо сохраняете исходный темп записи, выключите настройку. Запись выключает её автоматически. Для клавиатуры автоматическая пауза не добавляется.

Источник: [GetDoubleClickTime — Microsoft](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-getdoubleclicktime).

## JSON и библиотека

JSON редактируется напрямую: ключи, строки, числа и литералы подсвечиваются. Кнопка «Форматировать» выравнивает отступы; «Применить JSON» проверяет модель. Ошибка JSON блокирует переход к визуальному виду, сохранение и запуск. Во вкладке JSON название и повторы редактируются в JSON; поля визуального редактора отключены.

«Сохранить» добавляет или обновляет текущий макрос в списке. «Сохранить копию» в верхнем меню «…» создаёт отдельный файл. Нажмите элемент библиотеки, чтобы открыть его.

Библиотека: %LOCALAPPDATA%\MacroClicker\Macros. Настройки интерфейса и горячих клавиш: %LOCALAPPDATA%\MacroClicker\settings.json. Старые настройки горячих клавиш автоматически читаются из папки GameMacroClicker, если новых ещё нет.

Для переноса используйте **верхнее меню «…» → Экспорт JSON**, затем **Импорт макроса** слева. Старые JSON с массивом Steps преобразуются в один узел; выберите его окно или режим активного окна. Сохранённые назначения содержат имя процесса и заголовок, а не постоянный HWND. Если нет однозначного совпадения, выберите окно заново. Несохранённые изменения перед сменой сценария/закрытием требуют выбора «сохранить / не сохранять / отмена».

## Запись

1. Добавьте узлы всех приложений, в которых нужно записать действия, и явно выберите их окна. Узлы для подготовки могут быть пустыми. Режим активного окна не разрешает глобальную запись.
2. Нажмите «Записать действия» и подтвердите начало. Будет активировано первое окно.
3. Воспроизведите нужные действия. Записываются только окна, добавленные в сценарий. Видимый индикатор показывает число событий.
4. Нажмите **F10** или «Завершить запись». F10 не включается в записанный макрос.
5. Запись добавляется новыми узлами в конец сценария. Удалите пустые подготовительные узлы, если переходы к ним не нужны.
6. Просмотрите запись, отредактируйте интервалы и сохраните макрос.

Записываются клавиатурные нажатия/отпускания, повтор клавиши, кнопки и колесо мыши, экранные координаты, интервалы. Движение мыши ограничено 20 Гц; лимит — до 50 000 событий с резервом для завершающих отпусканий. Это воспроизведение действий, а не точная запись движения с частотой игровой мыши. Экранные координаты зависят от положения окон и мониторов.

Alt+Tab, Alt+Shift+Tab и Win+Tab не записываются как клавиши. При последующем рабочем действии в другом выбранном окне создаётся узел этого приложения.
Клик, активирующий неактивное окно, пропускается целиком — включая отпускание и движение с зажатой кнопкой. Для записи рабочего клика сначала активируйте окно, затем нажмите ещё раз.
Кнопки самого MacroClicker, F10 и назначенные сочетания старта/остановки воспроизведения не записываются.
Во время записи сочетания воспроизведения отключены как команды; завершение записи — F10 или кнопка в интерфейсе.
Фильтр исключает события из записи, но не блокирует их доставку Windows и целевому приложению.

Клавиши и кнопки, зажатые до начала записи или в постороннем окне, игнорируются до отпускания.
Отдельные отпускания без записанного нажатия не создают действия или пустые узлы.
Обычные Ctrl+C, Alt+Shift, Win+Space, Shift+Tab и перетаскивание сохраняются. Модификаторы буферизуются до распознавания рабочего или служебного жеста.
При уходе из целевого окна записанные удержания завершаются. Время вне целевого окна не добавляется как длинная пауза;
возврат в то же окно без рабочих действий в другом не создаёт лишний узел. Первое автоматическое переключение выполняется до включения перехватчиков.

Набранные клавиши могут содержать чувствительный текст — записывайте только нужный сценарий. Перехват существует только во время явно начатой записи и снимается при её остановке/закрытии приложения. Ввод самого MacroClicker и синтетические события отфильтровываются. Нажатие Ctrl+V записывается как сочетание; содержимое буфера обмена в сценарий не включается.

## Проверка и ограничения

При запуске проверяются все явно назначенные окна. Такие узлы активируют своё окно, включая восстановление свёрнутого. Узлы активного окна не переключают приложения. На ожиданиях и перед вводом проверяется фокус; при его потере сценарий останавливается. Перед координатным кликом проверяется приложение под курсором. Во время воспроизведения не следует параллельно управлять другими приложениями.

Уровень прав должен соответствовать целевому приложению. Код активации окна и ввод через SendInput не обходят ограничения Windows и приложения.

Автопроверки логики на Mac:

    dotnet run --project tests/EngineChecks/EngineChecks.csproj -c Release

Проверяется настоящий MacroRunner и модель данных с подменой Windows-ввода на тестовые реализации. HTML-интерфейс дополнительно проверяется в локальном браузерном предпросмотре; там нет Windows-ввода. Эти проверки не доказывают работу WebView2-хоста, глобальных горячих клавиш, записи или реакцию конкретной игры на Windows. Чек-лист реальной машины находится в WINDOWS-CHECKLIST.md.
