# Запуск MacroClicker

1. Скачайте `MacroClicker.exe` из [последнего релиза](https://github.com/8GagariN8/MacroClicker/releases/latest) и сохраните на локальный диск Windows.
2. Запустите EXE. Отдельная установка .NET не требуется. Если приложение сообщает об отсутствии WebView2, установите Microsoft WebView2 Runtime по инструкции в сообщении и повторите запуск.
3. Откройте нужное приложение. Создайте макрос и добавьте основную ноду. Можно выбрать приложение или оставить «Текущее активное окно».
4. Добавьте действия через «Редактировать» и сохраните макрос. Дополнительную ноду создайте кнопкой «Добавить условие» на основной карточке.
5. Нажмите «Старт» или `Ctrl+Alt+F8`. Для текущего окна перед запуском есть отсчёт 5 секунд — перейдите в нужное приложение. Явно назначенные окна активируются автоматически.
6. Повторное нажатие останавливает сценарий. Потеря фокуса также останавливает выполнение.

Если целевое приложение работает от администратора, запустите MacroClicker с теми же правами.

Инструкция встроена в EXE: кнопка «Справка» слева внизу. Для ошибок откройте «Журнал» → «Копировать» или «Папка журналов». Отдельные журналы запусков сохраняются в `%LOCALAPPDATA%\MacroClicker\Logs`.
