Microsoft Edge WebView2 Runtime — официальный офлайн-установщик x64

Нужен для интерфейса MacroClicker 2.1. Если MacroClicker уже открывается, устанавливать повторно не нужно.
Если приложение сообщает об отсутствии Runtime:
1. Запустите MicrosoftEdgeWebView2RuntimeInstallerX64.exe.
2. Следуйте шагам установщика Microsoft.
3. После установки снова запустите MacroClicker.exe.

Runtime устанавливается в Windows отдельно от приложения. Сам MacroClicker ничего не устанавливает автоматически.
Интернет для этого офлайн-установщика не нужен. Evergreen Runtime может самостоятельно обновляться по правилам Microsoft.
